# JS Mini Shop
A small shop system built with plain JS while learning the fundamentals.

# Projects

### 1. Shop Checkout (`shop-checkout.js`)
Calculates the total, average and price level of products using functions.

### 2. Mini Shop System (`githubShopCheckout.js`)
A shop object that can show products, add items to a cart, check stock and check out with a discount.

## What I learned and practised 
Functions and arrow functions
Arrays and `forEach`
Objects, methods and `this`
`Math.round`
Arrays of objects
